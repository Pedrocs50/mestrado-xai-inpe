# reports/

Figuras, tabelas e textos gerados pelos experimentos, prontos para entrar em artigos e na dissertação.

- `figures/`: gráficos em PDF/PNG, nomeados pelo experimento (ex.: `EXP-003-shap-resumo.pdf`)
- `tables/`: tabelas de métricas em CSV ou LaTeX

Tudo aqui deve ser reproduzível a partir de `experiments/`.
