# Cronograma do mestrado

Plano de trás para frente a partir da defesa, em 24 meses (M1 a M24).
**As datas e exigências oficiais (créditos, qualificação, prazos) devem ser conferidas no regimento do programa; os marcos abaixo são um ponto de partida meu.**

| Fase | Meses | Entregável | Milestone no GitHub |
|---|---|---|---|
| 0. Ingresso e organização | M1 | Ambiente, Zotero, vault de notas, repositório rodando | 00 Organização |
| 1. Revisão bibliográfica | M1-M4 | 40+ artigos lidos, notas de literatura, mapa do estado da arte | 01 Revisão |
| 2. Baseline | M3-M8 | Modelo LSTM reproduzido nos dados de plasma/clima espacial | 02 Baseline |
| 3. Experimentos de XAI | M7-M16 | Explicações (SHAP, LIME etc.) avaliadas; comparação com o baseline | 03 Experimentos XAI |
| 4. Primeiro artigo | M12-M18 | Preprint no Zenodo/arXiv e submissão | 04 Artigo 1 |
| 5. Qualificação | M14-M16 | Texto parcial e apresentação | 05 Qualificação |
| 6. Escrita da dissertação | M16-M22 | Capítulos completos, revisão do orientador | 06 Escrita |
| 7. Defesa | M23-M24 | Versão final, slides, banca | 07 Defesa |

## Ritos
- **Semanal (15 min):** o que andou, o que atrasou, o que entra na próxima semana.
- **Mensal:** reunião com orientador; atualizar o roadmap do GitHub Projects.
- **Por marco:** release no GitHub com DOI no Zenodo (ex.: `v0.1-baseline`).

## Datas que vão para a agenda "Mestrado"
- Prazos do programa (com lembretes de 30, 14 e 7 dias)
- Reuniões com orientadores
- Aulas e blocos de estudo
